Build Timeline

Phase 1 — Foundation (Days 1–3)
Oct 15 Blockchain Setup + Smart Contract v0 ▶
  • Create repo structure: contracts/, pipeline/, backend/, frontend/, docs/
  • Initialize Foundry project, install OpenZeppelin
  • Write VeriCarbon.sol — project registry, cell claims (H3 uint64), roles (submitter, validator, assessor, reviewer), submit + attest functions
  • Write unit tests for submitProject, cell exclusivity
  • Set up Python env: FastAPI, web3.py, shapely, h3, scikit-learn, rapidfuzz
  • Get Sepolia faucet funds, set up deployer wallet
  • Shortlist 3–4 pilot forest sites + 1 negative control
Oct 16 Blockchain AI Contract Complete + Satellite Pipeline ▶
  • Add 2-of-3 validator attestation, flagProject, resolveFlag, issueClaim
  • Add fuzz tests for cell exclusivity invariant
  • Deploy to Sepolia testnet
  • Build satellite pipeline: STAC fetch for pilot polygons, cloud mask, NDVI composites
  • Download and inspect 2 public registry datasets (Verra/Gold Standard exports)
Oct 17 AI Verification Pipeline + Hashing ▶
  • Tree-cover classifier with WorldCover weak labels; change detection; area estimate + confidence score
  • Decision rule: VERIFIED / REQUIRES_REVIEW / REJECT thresholds
  • Hash pipeline: dataset hash (scene IDs + checksums), model hash, result hash
  • Reproducibility script v0 that re-derives the result hash
  • Clean registry exports into common schema
Gate 1 (end of Oct 17): One project verified end-to-end via scripts, recorded on Sepolia testnet. Reproducibility script works. If missed → apply cut list immediately.
Phase 2 — Intelligence + Integration (Days 4–6)
Oct 18 AI Entity Resolution + Geospatial ▶
  • Build labeled pairs: real negatives + perturbed positives (name abbreviations, shifted polygons, rounded areas)
  • Entity resolution model: blocking by centroid, features (name/org/description similarity, area ratio, centroid distance, overlap), logistic regression baseline
  • Polygon → H3 cells conversion, overlap percentage, area similarity
  • Combine into duplicate-risk score with tunable weights
Oct 19 AI Blockchain Evaluate + Backend API ▶
  • Evaluate entity resolution: precision, recall, F1, confusion matrix; tune thresholds
  • Save evaluation report with figures (feeds the impact section)
  • Backend API: submit project, run verification pipeline, compute risk, call contract
  • Validator signing scripts
  • Error analysis on entity resolution misses
Oct 20 Blockchain End-to-End Integration ▶
  • End-to-end testnet test: Scenario A (duplicate detected, blocked) + Scenario B (legitimate, approved)
  • Fix integration bugs
  • Feature freeze for core logic
  • Start frontend skeleton: Next.js project, Leaflet map, basic routing
Gate 2 (end of Oct 20): Core pipeline works from the command line for both scenarios. Feature freeze. If missed → cut embedding-based similarity and extra demo projects.
Phase 3 — Product + Submit (Days 7–9)
Oct 21 Frontend Dashboard + Demo Screens ▶
  • Submission form with polygon drawing on map
  • Verification result page: map, NDVI evidence, confidence, hashes
  • Duplicate-blocked screen: side-by-side comparison, risk score, "registration blocked" state
  • Blockchain record view with Sepolia explorer links
  • Dashboard: projects verified, area verified, duplicates detected, projects flagged
Oct 22 Security Docs Security + Impact + Docs ▶
  • Run Slither on contracts, fix findings
  • Write security & data-integrity assessment (threat model from blueprint section 9)
  • Climate impact assessment: duplicates found, area/tonnes at risk, precision/recall, honest framing
  • Architecture diagram (SVG or Mermaid)
  • README with deployment instructions
  • Clean repo, add related-work section
Oct 23 Docs Video + Polish + Submit Early ▶
  • Rehearse and record 3-min demo video (problem → architecture → legitimate case → duplicate blocked → trust → impact)
  • Final UI polish, fix any broken flows
  • Complete Devpost submission: all fields, links, description
  • Verify every link from a logged-out browser
  • Submit on Devpost
Oct 24 — Buffer day. No new work. Fix only what is broken. Deadline is Oct 25, 11:59 PM UTC.
If you fall behind, cut in this order:
  1. Dashboard stats beyond basics → use static seeded values
  2. Embedding-based similarity → fall back to string similarity
  3. Three real validators → two scripted validators, threshold 2/2
  4. More than two demo projects → keep one legitimate + one duplicate

Daily Rhythm

Start (10 min): Pick 1–3 outcomes for today. Write them in the log.
Build: Focus on the day's deliverables. Commit often on feature branches.
End (10 min): Commit and push. Note done / blocked / tomorrow's first task.
Rule: main is always demo-able. Merge when a task works end-to-end.
